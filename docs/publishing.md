# 发布与试玩

1. 创建展示 EcoLoop 的 GitHub 仓库，将本发布目录内的内容上传至仓库根目录，包含 .github、.gitignore 和 .nojekyll 隐藏项。
2. 确认根目录有 README.md 和 index.html。无需再上传旧压缩包或开发归档。
3. 如需在线试玩，在仓库设置启用 Pages，选择当前默认分支的根目录。部署完成后，将实际生成的试玩地址加到 README 开头和仓库 About。
4. 查看 Verify EcoLoop 工作流结果，并在手机与桌面浏览器实际检查放牌、音效、撤销、重开和存档。

本轮准备的是本地文件，未创建远程仓库、推送或启用托管，没有虚构在线地址。

## 仓库简介参考

生态链 EcoLoop：基于食物链的 50 关放置解谜游戏。从个人创意出发，通过 AI 辅助编程、持续试玩反馈和自动验证迭代完成。
